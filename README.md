## Publicar en GitHub Pages

Este proyecto es un sitio estático, por lo que puede publicarse directamente desde GitHub Pages.

1. Crea un repositorio nuevo en GitHub, por ejemplo: `portafolio-jhans-luis-artica`.
2. Sube **todo el contenido de esta carpeta**, no la carpeta contenedora.
3. Verifica que `index.html` quede en la raíz del repositorio.
4. En GitHub entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`.
7. Guarda la configuración y espera a que GitHub publique el sitio.

La dirección normalmente tendrá este formato:

`https://TU-USUARIO.github.io/portafolio-jhans-luis-artica/`

> Si el repositorio se llama exactamente `TU-USUARIO.github.io`, la URL será `https://TU-USUARIO.github.io/`.
